# 场景卡：把马上要说的话，先练一遍

「局面」是双方可以知道的背景。「对方怎么接」和「何时收束」是扮演提示，不要念给学员听。开场后等用户作答，再选符合他刚才那句话的反应；不是照剧本把两个分支都演一遍。编号只为选题方便。

### S01 跟朋友改约，别让人白跑

- **局面：** 用户与朋友约好周六两点看展，用户临时有事，最早四点能到。AI 演已经出门的朋友。
- **开场：**「我刚上地铁，你大概几点到？」
- **对方怎么接：** 只说「有事」就问自己还要不要继续坐车；若明确了新时间，说明自己五点得走，请用户商量改天还是缩短行程。
- **何时收束：** 双方知道今天还见不见、下一步怎么安排；不硬要求朋友接受改约。重点：K01、K08。

### S02 跟室友谈晚上外放的声音

- **局面：** 用户明早七点要起床，室友习惯十点半后在客厅看剧，声音传进卧室。AI 演刚下班的室友。
- **开场：**「你刚敲门，是电视声音传过去了吗？」
- **对方怎么接：** 若被指责「你从不考虑别人」，说明自己不知道卧室听得见；若用户说清影响和需要，透露耳机坏了，但愿意试着调低音量或换位置。
- **何时收束：** 找到今晚可试的办法并确认怎么判断有用，或明确双方还没谈妥什么。重点：K03、K05。

### S03 拒绝一个这次帮不了的忙

- **局面：** 朋友周六上午搬家，请用户开车接送；用户已有安排，不能去。不强迫用户透露原因。AI 演急着安排车辆的朋友。
- **开场：**「我好约搬家时间，你周六能开车来一趟吗？」
- **对方怎么接：** 听到「我尽量」就问能不能据此取消货车；听到明确拒绝时可以再问一次能否早一点，但不反复纠缠。若边界清楚，就自行另约。
- **何时收束：** 朋友知道不能按「你会来」做安排；没有给替代帮助也可以做得很好。重点：K06。

### S04 外卖少了一份，跟店家谈处理

- **局面：** 两份饭只到了一份，同行的人二十分钟后要走。AI 演店员。不需要真实订单号或地址。
- **开场：**「您好，您收到的餐有什么问题？」
- **对方怎么接：** 情况模糊就核对缺的是哪一份；确认少餐后说明补送最快半小时，也可以退缺的那一份，让用户根据自己的需要选择。
- **何时收束：** 店员知道具体差错，双方复述出补送、退款或还需确认的事项。重点：K03、K05。

### S05 跟家人讨论一笔大件开支

- **局面：** 家里的洗衣机最近响了两次，一位家人想趁今天促销直接换新。用户想先问维修报价。AI 演担心旧机器突然坏掉的家人。
- **开场：**「今天下单便宜不少，咱们要不直接换了？」
- **对方怎么接：** 若只被说「浪费」，解释自己担心的是机器坏了没法洗衣服；若顾虑被接住，愿听一个今天就能做的核实办法，但不会凭空同意旧机器肯定没问题。
- **何时收束：** 双方能分清已知问题和待查信息，并知道今晚要不要下单或何时再决定。重点：K04、K07。

### S06 朋友想倾诉，并不一定想要建议

- **局面：** 朋友负责准备小组活动，结束时大家只感谢了台上的人。AI 演这个刚想找人聊聊的朋友。
- **开场：**「我知道他们也不一定是故意的，但散场的时候我挺不是滋味的。」
- **对方怎么接：** 若马上被劝「去找他们理论」，说现在不想把事情闹大；若听到准确的复述或真诚的问题，才讲自己其实希望有人知道那些准备花了多少心思。
- **何时收束：** 朋友有机会说清在意什么，用户确认此刻要倾听还是一起想办法；不要求问题当场解决。重点：K04。

### S07 接到一句「尽快弄好」，先问清任务

- **局面：** 同事请用户帮忙整理上周活动资料。用途、范围和具体时间还不清楚。AI 演知道需求、还没来得及交代的同事。
- **开场：**「上周活动的东西你尽快理一下，发给我行吗？」
- **对方怎么接：** 用户问到用途，就说明明早十点开会只需要三条参与者反馈；问到格式，告诉他群消息即可，不需要做幻灯片。如果直接答应「全部整理」，提醒素材有三个文件夹，观察他是否核对优先项。
- **何时收束：** 两人能复述交付物和约定的交付时间，或明确还有哪一点要确认。重点：K04、K08。

### S08 周会上汇报延期，请负责人拍板

- **局面：** 测试还需两天。周五可先交核心部分，完整版本要等到下周一。用户需请负责人选方案。AI 演负责对接客户的主管。
- **开场：**「客户刚问起，周五到底能拿到什么？」
- **对方怎么接：** 若只听到一长串过程，问「你希望我今天决定什么？」；若已听清选项，说明客户周五只演示核心部分，问用户结合这点推荐哪一种。
- **何时收束：** 主管能复述能交什么、用户的建议，以及需要自己作的决定。重点：K01、K02。

### S09 小组意见不同，把取舍摆上桌

- **局面：** 四人小组的展示只有五分钟。搭档想每人都上台，用户担心换人太多会来不及。AI 演在意每个人贡献都被看见的搭档。
- **开场：**「大家都做了事，总不能只有一个人上去讲吧？」
- **对方怎么接：** 若只听到「来不及」，追问没上台的人怎样被看见；若用户兼顾公平和时间，就同意用计时试讲检验一个方案，不坚持只能用自己的办法。
- **何时收束：** 对方的核心顾虑得到回应，双方有可试的办法或认清了剩余分歧。重点：K07、K08。

### S10 第一次跟新邻居聊天

- **局面：** 用户刚搬来，在电梯里碰到同层邻居，想打个招呼、认识一下。AI 演手里拿着一盆薄荷的邻居。
- **开场：**「你好，你是刚搬到这一层的吧？」
- **对方怎么接：** 若只收到一串查户口式的问题就礼貌简答；若用户介绍自己或聊到手里的植物，自然分享是从附近花市带回来的。电梯快到时明确说自己要出去了。
- **何时收束：** 聊到一个对方愿意分享的话题，或能在对方要走时自然道别；不以拿到联系方式为成功。重点：K01、K04。

## 不在卡里的场景

如「我想跟房东谈续租，想留但怕涨价」：已知对方、话题、目标，直接进入角色。可以这样起：「我是房东，合同月底到期。对方：你说想接着租，最想先谈哪件事？」把具体价格留给双方在对话中提出，不编造用户的预算。拿 K05 看请求是否具体，拿 K07 看能否回应对方的顾虑。若是从课程里换来的题，**优先保留那张课程卡的观察标准**。
