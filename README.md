# ACC · AI 表达能力教练

一个陪你**开口练**的中文 Agent Skill。可以从头学怎么把话说清楚，也可以直接排练今晚或明天要面对的一段对话。第一版不需要服务端、API Key 或 App：由支持 Agent Skills 的对话宿主读取 [SKILL.md](.agents/skills/communication-coach/SKILL.md)。支持语音输入的宿主可以用说的，文字对话也可以练；Skill 本身不采集录音，也没有接入 GPT Realtime API。

## 怎么开始

在克隆的 **ACC 仓库根目录**启动支持项目级 `.agents/skills/` 的宿主。以 Pi 为例：

```sh
cd ACC
pi
```

如果 Pi 首次启动时询问是否信任项目，先查看 Skill 内容，确认后允许加载。进入会话后输入 **`/skill:communication-coach`**，或直接说「陪我练表达」。也可以在命令后直接加上要练的事。如果宿主使用其他技能目录，把整个 [communication-coach 文件夹](.agents/skills/communication-coach/)复制到其技能目录，保留 `references/`，不要只复制入口文件。

| 我想做什么 | 可以直接这样说 |
|---|---|
| 从头系统学 | 「从第一个知识点开始，每次只出一题。」 |
| 专练一个薄弱点 | 「我常给一堆背景才说结论。带我练 K02。」 |
| 用自己的事情做课后题 | 「这道请求练习换成我跟房东谈续租，练完继续这课。」 |
| 从预设场景直接练 | 「练 S02，你当室友。我想谈谈夜里外放的声音。」 |
| 自定义整场对话 | 「明天我要向导师解释实验进度。你当赶时间的导师，让我先开口。」 |

## 两种模式

**[知识点学习](.agents/skills/communication-coach/references/curriculum.md)**：8 个递进知识点，每个都有反例、示范和 3 道当场开口的练习，共 24 题。先练「目的、结论、事实」，再练「倾听、请求、拒绝」，最后练「回应分歧、确认共识」。学一个就练一个；可以把任意一题替换成自己的情境，不会丢掉课程位置。

**[场景对练](.agents/skills/communication-coach/references/scenarios.md)**：10 张生活场景卡，涵盖改约、合租、拒绝帮忙、消费售后、家庭商量、朋友倾诉、任务澄清、工作汇报、小组分歧和邻里破冰。AI 演对方，你演自己；对方会根据你刚才说的内容接话，不会中途跳出来讲课。随时可以说「提示」「重来」「复盘」或「结束」。

例如在「周会汇报」里，你说「最近测试比较复杂，大家都在赶」，对方可能追问：「那周五客户到底能拿到什么？」如果你一开始就讲清能交什么，对方就不会重复问，而会和你讨论该选哪个方案。复盘只抓一句你真正说过的话，改一点，再试一遍。

进度只在当前对话里维护。想下次接着学，可以让教练给一行进度，例如「K04 · 下一题 2/3」，在新会话贴回即可。工作或生活案例用化名、去掉敏感细节就够了。

## 验收

运行 `python3 -m unittest discover -s tests` 检查 Skill 入口、资料链接、题量和课程编号；在对话宿主中用[交互验收用例](tests/dialogue-checks.md)检查逐轮行为。纯文字验收不代表语音链路或教学效果已经实测。
