# 交互验收（在对话宿主中手动运行）

每行另起一轮会话。箭头表示**等教练回应后**再说下一句。不检查回复是否逐字相同，检查的是教练有没有给人开口的机会，以及下一句是不是接着用户刚说的话。

| 用例 | 学员怎么做 | 应观察到什么 |
|---|---|---|
| 不明确的开始 | 「陪我练表达」 | 只问要系统学还是做场景，不发整套课程或问卷。 |
| 学完即练 | 「从 K02 学起」→「我觉得 A 不错」→ 按追问补充选择的依据 | 先说明一个方法并发第 1 题；听到含糊依据，追问而不代答。补充后针对原话给反馈。三题分轮进行，结尾能接 K03，不把跳过算成掌握。 |
| 在课中自定义 | 「学 K05，从第 2 题开始」→「换成请房东安排修水龙头」→「您看着处理就好」 | 仍是 K05 第 2 题；房东就模糊的请求追问。练完进入 K05 第 3 题，不误切到自由对练或下一课。 |
| 预设里的两种反应 | 「练 S08」→ A：「测试还在做，挺复杂的」；另起同场 → B：「周五能交核心部分，完整版周一交。我建议先交核心，需要您同意」 | A 引出对交付或决定的追问；B 已经说清的事不再问一遍，而是根据客户需要继续商量。扮演中不插入评分。 |
| 自定义并重演 | 「我要和导师商量延期，你演导师，我先说」→ 给出理由 →「复盘」→「从我解释原因那句重来」 | 直接采用这个自定义角色，让学员先说。复盘只引用实际回答、只改一点；重演从选中的位置开始，不强制从头填资料。 |
| 切换、暂停和接续 | 「学 K04，从第 2 题开始」→「先切换到场景 S06」→「暂停」→「回刚才那课」→「结束，给我续学位置」 | 暂停时不再追问，返回继续 K04 第 2 题；结束时不给新题。新会话粘贴这行进度即可续学，不需要声称读过历史聊天。 |
| 不制造反馈 | 「练 S03」→「我卡住了，提示一下」→「我不想练了，结束」 | 提示后仍由用户自己讲。没有有效作答就不评价成绩；不把转写文本当成声学测量，不声称能听出分贝或紧张程度。 |
